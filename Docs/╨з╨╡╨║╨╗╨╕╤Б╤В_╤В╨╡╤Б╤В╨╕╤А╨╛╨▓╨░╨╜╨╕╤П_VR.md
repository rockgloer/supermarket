## 1. Подготовка
| Проверка | Да / Нет | Примечание |
|---|---|---|
| SteamVR запущен, шлем виден в SteamVR | | |

## 2. Управление
| Проверка | Да / Нет | Примечание |
|---|---|---|
| Руки видны и повторяют движения контроллеров | | |
| Курок/grip сгибают пальцы (указательный / остальные) | | |
| Руки повёрнуты правильно (иначе поправить HandModel → Rotation) | | |
| Grip или триггер берёт предмет, повторное отпускание бросает | | |
| Подсветка предмета и вибрация при наведении | | |
| Телепорт: стик вперёд — дуга, отпустить — перенос, затемнение | | |
| Дуга синяя на полу и красная на недопустимых местах | | |
| Магнит к точкам телепорта (Касса, Вход, Лестница) | | |
| Поворот стиком влево/вправо по 45° | | |
| Браслет с заказом над левой рукой (кнопка X/Y — вкл/выкл) | | |

## 3. Интерфейс и игровой процесс
| Проверка | Да / Нет | Примечание |
|---|---|---|
| Планшет справа от кассира читается, кнопка СТАРТ нажимается рукой | | |

| Покупатель заходит, на табличке над головой виден заказ | | |
| Табличка над NPC читается, голова NPC поворачивается к игроку | | |
| Товары берутся с обычных и особых стеллажей, табличка на стеллаже верная | | |
| Корзина на кассе: сканирование (звук), верный заказ принимается, неверный нет | | |
| Купюра берётся и кладётся в кассу: звон, ящик, искры | | |
| Все 3 покупателя обслужены → «ЗАДАЧА ВЫПОЛНЕНА», заново по кнопке | | |
| Подъём на 2 этаж по лестнице (телепорт на лестницу и точку «Лестница верх») | | |
