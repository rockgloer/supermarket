# 🛒 Супермаркет VR 
### VR-симулятор кассира на Unity 6 · OpenXR · SteamVR

Вы играете за кассира двухэтажного супермаркета. Три покупателя — Анна, Борис и Вера — приходят со своими заказами. Собирайте продукты со стеллажей на двух этажах, складывайте их в корзину, пробивайте покупки на кассе и принимайте оплату. После обслуживания третьего покупателя появляется сообщение **«ЗАДАЧА ВЫПОЛНЕНА!»**

Проект поддерживает VR-режим через OpenXR и SteamVR, а также обычное управление с клавиатуры и мыши.

## 🚀 Быстрый старт

### 1. Скачать проект

На странице репозитория GitHub нажмите **Code → Download ZIP** и распакуйте архив. Также проект можно клонировать с помощью Git.

### 2. Открыть в Unity

1. Запустите **Unity Hub**.
2. Нажмите **Add → Add project from disk**.
3. Выберите папку проекта.
4. Откройте проект в совместимой версии Unity 6.

### 3. Запустить игру

1. Откройте сцену `Assets/Scenes/Supermarket.unity`.
2. Нажмите **Play**.
3. На кассовом планшете нажмите **СТАРТ**. В обычном режиме также доступны клавиши `R` для рестарта и управление с клавиатуры.

> При первом открытии Unity может потребоваться импортировать пакеты и дождаться завершения компиляции. Если сцена ещё не собрана, используйте меню **Supermarket → Собрать сцену**.

## 🥽 Установка и настройка VR

Для VR-режима необходим совместимый шлем, установленный SteamVR и поддержка OpenXR.

1. Откройте **Edit → Project Settings → XR Plug-in Management**.
2. На вкладке Windows (значок монитора) включите **OpenXR**.
3. В разделе OpenXR добавьте подходящий профиль контроллеров: **Oculus Touch**, **Valve Index** или **HTC Vive**. Если Unity предлагает исправления, нажмите **Fix All**.
4. В настройках OpenXR установите **Play Mode OpenXR Runtime = SteamVR**, если этот параметр доступен.
5. Запустите SteamVR и при необходимости установите его как OpenXR Runtime через меню настроек разработчика SteamVR.
6. В **Edit → Project Settings → Player** проверьте параметр **Active Input Handling**. Для проекта может потребоваться значение **Both**.
7. Подключите шлем, нажмите **Play** и наденьте шлем.
8. Для диагностики откройте меню **Supermarket → Проверка VR-настроек**. Режим отображается на стене у кассы.

### Важно

В проекте используется **OpenXR**. Плагин SteamVR из Asset Store может конфликтовать с OpenXR и для запуска этой версии проекта не требуется. Если Unity сообщает о конфликте, удалите плагин SteamVR из проекта, следуя подсказкам Unity. Не удаляйте установленное приложение SteamVR: оно используется как OpenXR Runtime.

## 🎮 Управление

| Действие | VR-контроллеры | Без VR |
|---|---|---|
| Перемещение | Отклоните стик вперёд, наведите дугу телепорта и отпустите стик | `W`, `A`, `S`, `D` |
| Поворот | Правый стик влево/вправо — поворот на 45° | Мышь |
| Взять / отпустить предмет | `Grip` или триггер — в зависимости от действия | ЛКМ |
| Взаимодействовать | Наведите луч и нажмите курок; удерживайте для некоторых действий | `E` или ЛКМ при наведении на кнопку |
| Бросить предмет | Отпустите хват | `Q` |
| Бег | — | `Shift` |
| Начать заново | Кнопка `A` после завершения | `R` |
| Пауза | Кнопка меню контроллера | `Esc` или `P` |
| Выход | Кнопка **ВЫХОД** на кассовом планшете | Меню паузы |

**Телепортация:** синяя дуга и круг показывают доступное место, красная дуга — недоступное. Отпустите стик, чтобы переместиться. Телепортация доступна на пол, площадку второго этажа и лестницу; на полки, прилавки и стены перемещаться нельзя.

**HUD:** на левом запястье в VR отображаются деньги, цель и текущие задания.

## 🧾 Как играть

1. Подойдите к покупателю у кассы и получите его заказ.
2. Найдите нужные товары на стеллажах первого и второго этажей.
3. Соберите заказ в корзину и поставьте корзину на кассу.
4. Примите оплату: покупатель платит купюрой, которую нужно положить в кассу.
5. Обслужите всех трёх покупателей. Чем быстрее выполнены заказы, тем больше баллов можно получить.

> Основная цель: правильно собрать и продать товары для Анны, Бориса и Веры.
