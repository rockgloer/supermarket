# Супермаркет VR v2 (Unity 6 + OpenXR / SteamVR)

Вы — кассир двухэтажного супермаркета. Приходят 3 покупателя (Анна, Борис, Вера), называют заказ,
вы собираете продукты со стеллажей (1 и 2 этаж) в корзину, ставите корзину на кассу,
покупатель платит купюрой, вы кладёте купюру в кассу. После третьего — «ЗАДАЧА ВЫПОЛНЕНА!».

## Выход из игры (v9)
- На кассовом планшете справа внизу красная кнопка **ВЫХОД**: первое нажатие — «ТОЧНО?», второе (в течение 3 секунд) закрывает игру.
- **Меню паузы:** Esc или P на клавиатуре, кнопка меню на левом контроллере. Пункты: ПРОДОЛЖИТЬ, НАЧАТЬ ЗАНОВО, ВЫЙТИ ИЗ ИГРЫ (с подтверждением). Игра на паузе, телепорт и хват отключены. Кнопки нажимаются рукой в шлеме или клавишей E / ЛКМ при взгляде на кнопку.
- В EXE закрывает приложение (`Application.Quit`), в редакторе останавливает Play Mode. Вид: `Menu_Preview.png`.

## ВАЖНО: уберите плагин SteamVR из проекта
Плагин SteamVR из Asset Store конфликтует с OpenXR (это и есть «XR конфликтуют»).
Сама программа SteamVR остаётся и работает как рантайм OpenXR, плагин в проекте не нужен.
При открытии проекта Unity сама предложит его удалить — нажмите «Удалить плагин».
Вручную: удалить папки Assets/SteamVR, Assets/SteamVR_Input, Assets/SteamVR_Resources,
Assets/StreamingAssets/SteamVR. Если в Package Manager есть пакет OpenVR — удалите его (Remove).

## Как обновить ваш проект
1. Закройте Unity. Распакуйте архив во временную папку.
2. Скопируйте из архива папки `Assets` и `Packages` в ваш проект с заменой (Replace).
   Старую папку Assets/SteamVR сначала удалите.
3. Откройте проект. Ответьте на окна (удалить SteamVR → «Удалить плагин», собрать сцену → «Да»).
   Если окна нет: меню Supermarket → Собрать сцену.

Новый проект с нуля: Unity Hub → Add project from disk → папка SupermarketVR.

## Настройка VR (один раз)
1. Edit → Project Settings → XR Plug-in Management → вкладка Windows (монитор) → галочка OpenXR.
2. Там же слева OpenXR → Enabled Interaction Profiles → «+»: Oculus Touch, Valve Index, HTC Vive.
   Красные/жёлтые значки → Fix All.
3. Внизу в OpenXR: Play Mode OpenXR Runtime = SteamVR.
4. В SteamVR (меню → Настройки → Разработчик): «Set SteamVR as OpenXR runtime».
5. Edit → Project Settings → Player → Active Input Handling = Both (если Unity не включила сама).
6. Включите SteamVR и шлем (Quest — Link), нажмите Play, наденьте шлем.
Проверка: меню Supermarket → Проверка VR-настроек. Надпись на стене у кассы покажет режим.

## Руки и управление
Руки — одна цельная гладкая сетка на скелете (15 костей, как у настоящих VR-рук): сужающаяся к запястью ладонь,
перепонки между пальцами, большой палец с бугром. Цвет — тёмный матовый (как в Oculus Home); светлая кожа:
в SupermarketBuilder.cs замените Tex_Hand на Tex_HandSkin (в MakeHand) и пересоберите сцену.
Пальцы двигаются по аналоговым значениям контроллера: курок — указательный, grip — остальные три,
касание кнопок или стика — большой палец. Когда рука держит предмет, пальцы остаются сжатыми.
Предмет, к которому тянется рука, подсвечивается, контроллер вибрирует при наведении, хвате, броске и телепорте.
Левая рука — зеркальная копия правой (отдельная сетка и кости, без отрицательного масштаба).
Над левой рукой, когда вы на неё смотрите, показывается «браслет» с текущим заказом (кнопка X/Y — вкл/выкл).
Файлы: Assets/Models/HandSkin.bytes (данные для сборки), HandSkin.obj (для просмотра), Tools/hand_skin.py (генератор).

ТЕЛЕПОРТ (как в SteamVR): отклоните любой стик вперёд — появится дуга. Синяя дуга и круг — можно переместиться,
красная — нельзя. Отпустите стик — экран на мгновение темнеет и вы оказываетесь в точке. Телепортироваться можно
на пол, перекрытие 2 этажа и лестницу (на полки, прилавок и стены — нельзя). Плавной ходьбы в шлеме больше нет.
Стик влево/вправо — поворот по 45°. Grip или триггер — взять/отпустить. Кнопка A — рестарт после финала.

Без шлема: WASD, мышь, ЛКМ (первый клик захватывает курсор) — взять/отпустить, колёсико — дальность руки,
Shift — бег, Esc — курсор, R — рестарт.

Если в шлеме руки повёрнуты не так, как держите контроллер: в Hierarchy откройте Player → RightHand (и LeftHand) →
HandModel и поменяйте Rotation (например X на 30 или -30). Дуга телепорта идёт от направления пальцев руки;
дополнительно её наклон можно менять в компоненте VRPlayer (поле Aim Pitch Offset).

## Покупатели, товары, окружение (v5)
- NPC собраны из отдельных частей: при ходьбе качаются ноги и руки, голова поворачивается к игроку (до 75° по горизонтали).
  Если нужны свои модели — Assets/Models/Custom (см. ниже), у них анимации не будет.
- ВСЕ товары на стеллажах рабочие: их можно взять, положить в корзину и продать. На вывеске каждого обычного
  стеллажа перечислены товары по полкам (сверху вниз). В каждый заказ добавлен один такой товар.
- Вокруг здания: тротуар у входа, дорога, кусты вдоль стен, деревья и ели (Nature_Preview.png).

## Таблички и указатели (v7)
- Над каждым покупателем — табличка с его именем и списком заказа (читается и спереди, и сзади), сверху короткая реплика.
- На каждом стеллаже — статичная табличка со списком товаров по полкам (сверху вниз), повёрнутая к проходу.
  Она никуда не поворачивается за игроком.
- Внизу у лестницы стоит указатель со списками товаров обоих этажей, на 2 этаже при выходе с лестницы — список второго этажа.
- Надписи больше не просвечивают через стены: для них свой шейдер Assets/Shaders/Text3D.shader
  (материал создаётся сборщиком сцены в Assets/Resources/Text3D.mat). Если надписи вдруг стали розовыми или пропали —
  удалите Assets/Resources/Text3D.mat и пересоберите сцену; значит шейдер не скомпилировался, пришлите ошибку из Console.
- Кусты отодвинуты от стен и стали меньше, внутрь здания не заходят.

## Планировка
Вход (дверь) справа на южной стене, касса слева. Ряды: МОЛОКО и ХЛЕБ — 1 этаж ряд A, НАПИТКИ и ФРУКТЫ — ряд B,
МЫЛО и ХЛОПЬЯ — 2 этаж (лестница у входа справа). Корзина стоит рядом с кассой.

## Свои модели покупателей
Положите Customer1.fbx/.obj (Анна), Customer2 (Борис), Customer3 (Вера) в Assets/Models/Custom,
затем Supermarket → Собрать сцену. Подробности — Assets/Models/Custom/README.txt.

## Как устроены файлы моделей
Для каждого предмета в Assets/Models лежит .obj (чтобы открыть в Blender или «Просмотре 3D») и .parts —
те же данные в формате, который сцена читает напрямую, минуя импортёр OBJ. Руки: HandSkin.bytes.
Люди: Person_*.parts (части тела отдельно для анимации). Всё это создаётся скриптами в папке Tools
(generate_models.py, hand_skin.py): если захотите изменить модели, правьте их, запускайте python и пересобирайте сцену.

## Если что-то не так
- Красные ошибки из папки SteamVR — удалите плагин (см. выше).
- VR не стартует — смотрите надпись РЕЖИМ на стене и Console.
- Розовые материалы — удалите папку Assets/Materials и пересоберите сцену.
- Не скачался пакет — Package Manager → Unity Registry → установите Input System, XR Plug-in Management, OpenXR.
- Окна непрозрачные — пересоберите сцену (Supermarket → Собрать сцену).
